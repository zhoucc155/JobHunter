# JobHunter · BOSS 直聘智能求职助手

一个本地运行的 Chrome 扩展，帮你在 BOSS 直聘上更高效地完成「采集岗位 → AI 匹配分析 → 生成真人风打招呼文案 → 投递」的闭环。文案由扩展内调用 DeepSeek 本地生成，**账号与数据都留在你自己的浏览器里**，不上传任何服务器。

> 仅供个人求职自用。请遵守 BOSS 直聘用户协议与平台风控规则，合理使用自动投递节奏，避免高频触发风控。

---

## 功能特性

- **岗位采集**：按意向关键词 + 城市批量采集岗位，支持按期望薪资过滤、过滤不活跃 HR / 猎头岗位、过滤关键词排除。
- **AI 匹配分析**：用你的简历文本做匹配度分析，标记高匹配岗位。
- **真人风打招呼文案**：基于简历事实生成自然语流、单段、不分段、硬上限 160 字的打招呼文案（强调可迁移能力、不自我否定）。
- **半自动 / 自动投递**：
  - 半自动：AI 生成文案后逐条确认发送。
  - 自动：勾选后批量自动发送并带随机间隔与风控保护（每日上限 + 安全验证熔断）。
- **投递统计**：今日速览（新发现 / 高匹配 / 已投递）+ 进度概览环形图。
- **面板交互**：展开时点击面板及悬浮球以外的任意处自动收起；投递确认卡 / 诊断卡遮罩不误关。

## 安装

1. 克隆本仓库（或下载 ZIP 解压）：
   ```bash
   git clone <你的仓库地址>
   cd JobHunter
   ```
2. 打开 Chrome，进入 `chrome://extensions`。
3. 右上角开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库内的 **`extension/`** 目录。
5. 扩展加载后，浏览器右下角出现 `JH` 悬浮球，点开即可使用。

## 配置（首次使用）

在面板的「我的简历」页填写：
- **姓名 / 称呼**：用于文案开头（如「您好，我是张三」）。
- **简历图片**：投递时发送给招聘方（建议长图，≤4MB）。
- **简历文字版**：用于 AI 匹配分析与文案生成，越完整越精准。

在「采集配置」页填写：
- **意向岗位关键词 / 意向城市**
- **期望薪资**（如 `15-25K`，可开启「按期望薪资过滤」）
- **过滤岗位关键词**（命中即排除，如 `外包,销售,保险`）
- **单次采集数量 / 每日投递上限**（每日上限默认 30，保护账号）
- **DeepSeek API Key**（仅存本地，不上传任何服务器）

---

## 使用流程

1. 「岗位管理」→「岗位采集」拉取岗位。
2. 可选「匹配度分析」标记高匹配。
3. 「文字投递」或「图片投递」开始投递；勾选「自动投递」可批量自动发送（带随机间隔与风控保护）。
4. 「投递记录」查看今日速览与累计进度。

## 目录结构

```

├── extension/          # Chrome 扩展源码（加载此目录）
│   ├── manifest.json
│   ├── background.js    # 后台：DeepSeek 文案生成、调度
│   ├── content/
│   │   ├── panel.js      # 面板 UI 与投递主逻辑
│   │   ├── panel.css     # 面板样式
│   │   ├── collector.js  # 岗位采集与薪资解析
│   │   ├── deliver.js    # 单岗位投递执行
│   │   └── utils.js      # 公共工具
│   └── ...
├── diag/               # 页面诊断脚本
├── greeting-*.md       # 打招呼文案方案设计文档
├── 版本说明文档.txt      # 版本迭代记录
└── 采集配置.txt         # 采集配置说明
```
