# JobHunter 智能求职助手（BOSS直聘版）

自动采集岗位 → AI 匹配度分析 → 半自动安全投递（简历图 + 定制文案）。

## 安装步骤

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本 `extension` 文件夹
4. 打开 [BOSS直聘](https://www.zhipin.com) 并**登录你的账号**
5. 点击浏览器工具栏的插件图标（或页面右上角的 JH 悬浮球），面板从右上方滑出

## 使用流程

### ① 我的简历
- 上传简历图片（投递时发给招聘方，建议清晰长图，≤4MB）
- 粘贴简历文字版（AI 匹配分析与文案生成的依据，越完整越准）→ 保存

### ② 采集配置
- 意向岗位关键词、期望薪资、意向城市（多个用逗号隔开）
- 过滤关键词（命中即排除，如"外包,销售"）
- 勾选过滤 7 日不活跃 HR / 猎头代招岗位
- 单次采集数量（默认 20，上限 50）、每日投递上限（默认 30）
- **DeepSeek API Key**：到 [platform.deepseek.com](https://platform.deepseek.com) 创建，仅存本地浏览器，不上传任何服务器 → 保存

### ③ 岗位管理
1. **岗位采集**：自动跳转搜索页 → 模拟真人滚动浏览列表 → 后台逐个打开详情页（每个停留 3~8 秒）补采完整 JD、HR 活跃度、猎头标识 → 过滤后入库。采集期间**保持标签页打开**，可以切去干别的。
2. **匹配度分析**：AI 解析每个 JD 的核心能力关键词 × 你的简历 → 0~100 分（≥75 绿色 / 50~74 黄色 / <50 红色），悬停分数圈可看评分理由。
3. **投递**：勾选岗位（可全选）→ 点「投递选中」→ 每个岗位弹出确认卡片：AI 按四段范式（职业定位 → 最匹配案例 → 第二能力 → 自然收尾）生成 200 字内定制打招呼文案（**可编辑**）→ 点「确认发送」后自动执行：
   - 详情页点击「立即沟通」（BOSS 系统自动发送破冰话术）
   - 跳转聊天页定位会话 → **先发简历图片** → 停 2~4 秒 → **再发定制文案**（保证 HR 会话预览显示文案而非 [图片]）
   - 岗位之间自动间隔：打散式随机等待（主流 14~26 秒，偶尔手顺 10~16 秒 / 分心 26~42 秒），且每 4~7 个岗位随机来一次 1~2.5 分钟长休息，模拟真人节奏规避风控；间隔期间并行预生成下一岗文案，把 API 延迟藏进等待里（零风险提速）
4. **删除**：勾选后点「删除选中」。

### ④ 投递记录
- 成功 / 跳过 / 失败逐条记录，历史累计统计
- 今日投递计数与每日上限展示
- 已投递岗位不会被再次采集、不会重复投递

## 账号安全机制（重要）

| 机制 | 说明 |
|---|---|
| 半自动投递 | 每条投递必须人工点「确认发送」，人在环中，行为模式接近真人 |
| 每日上限 | 默认 30 次/天，达到即停止（可在配置中调整，不建议超过 50） |
| 随机节奏 | 采集滚动、详情停留、消息输入全部模拟真人随机节奏，逐字打字 |
| 验证码熔断 | 一旦检测到滑块/安全验证，立刻停止一切自动操作并提醒你手动处理，**绝不自动破解** |
| 重复保护 | 已沟通过的岗位自动跳过；本地日志防重复投递 |

**使用建议**：
- 每天投递量控制在 30 以内，分上午/下午两批更自然
- 触发过一次验证码后，当天不要再使用自动功能
- 不要在深夜（0~6 点）批量操作

## 常见问题

**Q: 采集/投递不工作了？**
BOSS 直聘前端经常改版，DOM 选择器可能失效。所有选择器集中在 `content/selectors.js`，按 F12 检查页面元素后更新对应选择器即可，无需改动其他代码。

**Q: 简历图片没发出去，文案发出去了？**
会话定位或上传控件偶发失败时，插件会标记「待补发」并记录在投递记录中——**无需手动处理**：本轮投递队列结束后，插件会自动对所有待补发岗位重新打开聊天页、定位会话并补发缺失的内容（只补缺失部分，已发过的文案/图片绝不重复发送）。也可以随时点击岗位上的「待补发·点击补发」标签立即补发。若自动补发仍失败，会保留标记并在下一轮投递结束后再次自动重试。

**Q: 城市不生效？**
内置了 28 个主要城市的编码（见 `selectors.js` 的 `JH_CITY_CODES`）。小众城市请先手动在 BOSS 搜索页选好城市，再点「岗位采集」（在搜索页发起采集时直接用当前页面）。

**Q: DeepSeek 收费吗？**
按 token 计费，非常便宜：分析 20 个岗位 + 生成 20 条文案约几分钱到几毛钱。
